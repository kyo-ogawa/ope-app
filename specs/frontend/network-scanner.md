# IPスキャナー仕様

## 概要

ローカルネットワーク上のデバイスを検出するスキャナー機能。

## 機能要件

### 1. インターフェース選択

利用可能なネットワークインターフェースを一覧表示し、スキャン対象を選択。

表示項目:
- インターフェース名（例: en0, eth0）
- IPアドレス
- サブネットマスク

### 2. スキャン実行

選択したインターフェースのサブネット内をスキャン。

表示項目:
- プログレスバー（現在/総数）
- 現在スキャン中のIP
- 検出済みデバイス数

### 3. 結果表示

検出されたデバイス一覧。

| カラム | 説明 |
|-------|------|
| IP | IPアドレス |
| MAC | MACアドレス |
| Hostname | ホスト名（取得可能な場合） |
| Vendor | MACベンダー（取得可能な場合） |
| アクション | デバイスとして追加 |

### 4. デバイス追加

スキャン結果からデバイスを設定に追加。

- 追加ボタンクリック → ダイアログ表示
- 名前とポートを入力
- 設定に追加

## Tauri IPC

### コマンド

| コマンド | 説明 |
|---------|------|
| `get_network_interfaces` | インターフェース一覧取得 |
| `scan_network` | スキャン実行 |

### イベント

| イベント | ペイロード | 説明 |
|---------|-----------|------|
| `scan_progress` | ScanProgress | スキャン進捗 |

## 状態管理

```typescript
const [interfaces, setInterfaces] = useState<NetworkInterface[]>([]);
const [selectedInterface, setSelectedInterface] = useState<NetworkInterface | null>(null);
const [isScanning, setIsScanning] = useState(false);
const [progress, setProgress] = useState<ScanProgress | null>(null);
const [results, setResults] = useState<ScannedDevice[]>([]);
```

## スキャンフロー

```
1. get_network_interfaces 呼び出し
2. ユーザーがインターフェース選択
3. scan_network 呼び出し
4. scan_progress イベントで進捗更新
5. 完了時に ScanResult を受信
6. 結果を表示
```

## エラーハンドリング

- インターフェース取得失敗 → エラーメッセージ
- スキャン中断 → "スキャンを中断しました"
- 権限不足 → "管理者権限が必要です"
