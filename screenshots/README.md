# スクリーンショット撮影ガイド

このディレクトリには、README.mdで使用するスクリーンショットを保存します。

## 必要なスクリーンショット

### 1. dashboard.png
**内容**: ダッシュボード画面
- ターゲットデバイスのステータスカード（ONLINE/OFFLINEの状態）
- カスタムボタンのセクション
- カスタムモニターの表示（あれば）

**撮影手順**:
1. アプリケーションを起動
2. サイドバーから「Dashboard」を選択
3. いくつかのデバイスを登録・監視した状態で撮影
4. スクリーンショットを `dashboard.png` として保存

### 2. ip-scanner.png
**内容**: IPスキャナー画面
- スキャン結果のテーブル
- デバイス情報（名前、IP、MAC、ベンダー）
- 「Add to Devices」ボタン

**撮影手順**:
1. サイドバーから「IP Scanner」を選択
2. 「Start Scan」をクリックしてスキャンを実行
3. 検出されたデバイスが表示されている状態で撮影
4. スクリーンショットを `ip-scanner.png` として保存

### 3. flow-viewer.png
**内容**: フロー可視化画面
- デバイスノード
- OSCメッセージフローの矢印/接続線
- ノードの配置

**撮影手順**:
1. サイドバーから「Flows」を選択
2. 複数のデバイスが登録されている状態
3. OSCメッセージの送受信が発生している状態で撮影
4. スクリーンショットを `flow-viewer.png` として保存

### 4. configuration.png
**内容**: 設定画面
- タブ（Devices, Targets, Settings, Buttons, Logics, Custom Monitors）
- いずれかのタブの設定内容

**撮影手順**:
1. サイドバーから「Configuration」を選択
2. 「Devices」タブまたは「Buttons」タブなど、内容が充実しているタブを選択
3. 設定項目が見やすい状態で撮影
4. スクリーンショットを `configuration.png` として保存

## 撮影のコツ

- **解像度**: 1920x1080以上推奨
- **テーマ**: ライトモードとダークモードのどちらでもOK（統一感を持たせるため、すべて同じテーマで撮影推奨）
- **内容**: 実際の使用例を示すため、適度にデータが入っている状態で撮影
- **プライバシー**: 実際のIPアドレスやデバイス名が含まれる場合は、適宜編集してください

## macOSでのスクリーンショット撮影方法

- **全画面**: `Command + Shift + 3`
- **範囲指定**: `Command + Shift + 4`
- **ウィンドウ指定**: `Command + Shift + 4` → `Space`

スクリーンショットは自動的にデスクトップに保存されます。

## 画像の最適化（オプション）

スクリーンショットのファイルサイズを削減したい場合:

```bash
# ImageMagickを使用（インストールが必要）
convert dashboard.png -quality 85 dashboard.png

# または、macOSのプレビューアプリで「ファイル」→「書き出す」→品質を調整
```
